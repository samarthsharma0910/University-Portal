# University Portal System

A web-based application designed to centralize and simplify access to various university services. The system integrates multiple student-oriented modules such as hostel management, transport details, fee tracking, academic resources, placement information, and mentorship into a single platform.


## Overview

In many institutions, student services are distributed across different platforms or managed manually, leading to inefficiency and lack of accessibility. This project provides a unified dashboard that enables students to access all essential services in a structured and user-friendly manner.



## Features

- Secure student authentication system  
- Centralized dashboard for navigation  
- Hostel management with room selection and booking  
- Transport module with route and timing details  
- Fee management with structured breakdown  
- Library access and resource management  
- Previous Year Questions (PYQ) section  
- Placement information system  
- Mentor-mentee interaction module  
- AI chatbot for basic assistance  


## Tech Stack

Frontend:
- HTML  
- CSS  
- JavaScript
  
Backend:
- Node.js  


## System Modules

- Authentication Module – Handles login and user access  
- Dashboard Module – Central interface for navigation  
- Hostel Module – Room listing, filtering, and booking  
- Transport Module – Bus routes and scheduling  
- Fee Module – Displays financial details  
- Library Module – Book search and access  
- PYQ Module – Academic preparation resources  
- Placement Module – Opportunity tracking  
- Mentor Module – Mentor interaction and session requests
